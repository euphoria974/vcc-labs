# VCC-Labs

This repository contains labs for the Virtualization and Cloud Computing class at INSA Toulouse for the fall 2026 semester.

For each lab, there is a folder with the lab number (e.g. `TP1`). These folders include a `README.md` file with answers to technical questions asked in the assignment, along with files produced while doing the assignment. These files might require other example files which aren't included in this repo to work correctly.
